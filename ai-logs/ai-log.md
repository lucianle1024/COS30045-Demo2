# Exercise 4.1: Draw SVGs

## Use of AI

I used Claude (Anthropic) to help with parts of this exercise.

### 1. Original house drawing code
- **What I asked:** I gave Claude a reference image of a house and garden and asked for D3.js code to draw something like it, as simple and readable as possible.
- **What Claude produced:** An HTML file using D3.js that draws the scene with SVG shapes (`rect`, `circle`, `polygon`, `path` and `text`).
- **Where it is used:** The base of the drawing in `4-1.html`.

### 2. Annotated house image
- **What I asked:** I uploaded a screenshot of my house and asked Claude to point out the coordinates of one example of each shape type.
- **What Claude produced:** `img/annotated-house.png`, my screenshot with the origin (0, 0), the x and y axes, and labels showing the coordinates for each shape type (`rect`, `circle`, `ellipse`, `polygon`, `line` and `path`, plus `text`).
- **Where it is used:** Step 2 of the exercise, shown on my webpage.
